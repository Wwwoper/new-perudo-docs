# Стратегия тестирования

Статус: требования к тестированию; физическая реализация отложена.

## Уровни

- **Unit:** отдельные правила, функции, валидаторы, вычисления и переходы.
- **Property-based:** инварианты на множестве входных данных.
- **Integration:** взаимодействие модулей и сквозные сценарии.
- **Contract:** совместимость публичных моделей и межмодульных интерфейсов.

## Game Domain

Валидатор ставок, ограничение количества, NORMAL/PALIFICO, Dudo, потеря кубика, выбывание, очередность, завершение партии. Свойства: неотрицательные кубики, только активные в очереди, недопустимая команда не меняет состояние, ставка разрешается один раз, бросок не повторяется. Интеграционный сценарий: создание → раунд → броски → ставки → Dudo → разрешение → потеря кубика → следующий раунд → завершение.

## Event Storage

Атомарность, идемпотентность command_id, конфликт payload, непрерывность sequence, snapshot, fallback, восстановление с начала, повреждённый журнал, неизвестное событие/версия, отсутствие мигратора, итоговые инварианты.

## S2–S4

S2: циклическая очередность, неактивные игроки, максимум/минимум и равенства, зоны, ставки, факты/предположения, восстановление, скрытая информация. S3: грани, джокеры, PALIFICO, единицы, нулевое требование, разное число кубиков, валидация и промежуточные ответы. S4: точные дроби, биномиальная модель, граничные значения, сумма распределения, 0%/100%, точное сравнение, равенства, допуски, интерпретация частоты.

## Exercise и Evaluation

Сохранение экземпляра, воспроизводимость по seed/версиям, отсутствие эталона в public model, формат/поля, частичная оценка, follow-through credit, optional steps, исправление после feedback, неограниченные отправки, отсутствие раннего раскрытия, диагностика.

## Learning Progress

Переходы статусов, повторение, несколько типов успешных упражнений, отдельный учёт подсказок, сброс с историей, отсутствие дубликатов задач и независимый прогресс навыков.

## Безопасность

Проверить, что закрытые кубики не попадают в public models, эталон не раскрывается до завершения, скрытые значения отсутствуют в логах/ошибках/feedback, UI не подменяет доменную проверку и восстановление не повторяет случайность.
