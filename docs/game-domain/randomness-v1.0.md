# Randomness Contract

Версия: 1.0.

## Источники случайности

- `GameRandomSource` — криптографически стойкий источник для реальной партии. Сохраняются фактические результаты бросков и выбор первого игрока; seed не требуется.
- `ExerciseRandomSource` — детерминированный источник для упражнений. Сохраняются seed, `generator_id`/version, config, ruleset id/version и готовый экземпляр.
- `TestRandomSource` — фиксированная последовательность для тестов; исчерпание последовательности вызывает явную ошибку.

Общий логический интерфейс — `RandomSource.randbelow(upper_bound)`. Источник случайности является зависимостью сценария, а не частью `GameState`.

Восстановление состояния не повторяет броски и не выбирает заново первого игрока. Криптографическая проверка честности бросков и дополнительный аудит случайных операций не входят в MVP.
