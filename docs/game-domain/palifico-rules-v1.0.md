# Palifico Bid Rules

Версия: 1.0. Статус: согласованная проектная формализация; отдельные трактовки требуют сверки с официальной инструкцией Zygomatic 2022.

## Подтверждённые правила модели

- Palifico действует один следующий раунд.
- При двух активных игроках на старте раунда Palifico не применяется.
- В Palifico единицы не являются джокерами.
- Начальная ставка может использовать любую грань 1–6.
- Право игрока менять грань после собственного фактического объявления Palifico сохраняется до конца партии.
- `round_mode` описывает текущий раунд; `has_declared_palifico` — историческое право конкретного игрока.

## Формализация повышения

Для игрока без права изменения грани количество должно увеличиваться при сохранении грани.

Для игрока с правом изменения грани допустимо увеличить количество с любой гранью либо сохранить количество и выбрать более высокую грань. Уменьшать количество или сохранять количество с той же/более низкой гранью нельзя.

Это проектная формализация таблицы повышений, а не дословная цитата официальной инструкции. Сценарий `3 Paco` → `7 × 2` остаётся предметом отдельной проверки.

## Контекст валидатора

`BidValidationContext` содержит `round_mode`, `previous_bid`, `has_declared_palifico`, `active_player_count`, `ruleset_id`, `ruleset_version`. `BidValidator` не изменяет игровое состояние.
