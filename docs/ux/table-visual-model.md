# Визуальная модель игрового стола

Версия: 0.1. Согласовано.

## Зоны

Зона собственного игрока, зоны соперников, области кубиков, центр стола, текущая ставка, индикатор хода и информационная область.

Собственные кубики открыты. Кубики соперников показаны закрытыми изображениями; их количество видно, значения граней скрыты.

## Адаптивность

На широком экране участники располагаются вокруг стола; на мобильном используется компактная раскладка. Идентичность участника определяется устойчивым `player_id`, а не позицией на экране.

## Режимы представления

- `FULL` — полное разрешённое представление;
- `FOCUS` — выделение области задания;
- `COMPARE` — сопоставление элементов;
- `HISTORY` — последовательность состояний;
- `PARTIAL` — ограниченное представление упражнения.

`TableView` описывает визуальное состояние, `TableLayout` — расположение областей для viewport. Логические модели: `PlayerView`, `BidView`, `TableView`, `TableTransition`, `TableRegion`, `TableLayout`.

`TableRegion`: region_id, region_type, owner_id, element_id, display_order. Типы: `PLAYER_ZONE`, `DICE_AREA`, `CENTER`, `CURRENT_BID`, `TURN_INDICATOR`, `INFO_AREA`.

Для S2.6 сначала используются статичные последовательные состояния; анимация отложена. Каждое событие применяется один раз; `TURN_ADVANCED`, а не `BID_PLACED`, меняет текущего игрока.

Визуальная модель получает только разрешённые данные. Закрытые значения не присутствуют в скрытых атрибутах, клиентском состоянии или доступных UI данных. Изменение viewport не меняет идентичность участников, очередность, ставку, количество кубиков и доступность скрытых значений.
