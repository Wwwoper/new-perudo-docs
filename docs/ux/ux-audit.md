# UX-аудит Perudo

Основа: семь предоставленных скриншотов.

## Основные проблемы

1. Перегруженность текстом и терминами.
2. Неочевидное следующее действие.
3. Смешение справки и текущей задачи.
4. Слабая визуальная иерархия.

## Приоритеты

### P0

- На каждом экране очевидно основное действие.
- Условие упражнения отделено от объяснения правил.
- Ответ и отправка имеют ясное состояние.
- Feedback связан с конкретным действием пользователя.

### P1

- Сократить длинные пояснения на основном экране.
- Перенести подробные правила в контекстную справку.
- Использовать последовательное раскрытие информации.
- Разделить игровое состояние, условие задания и ответ.
- Показывать прогресс, не отвлекая от задания.

### P2

- Унифицировать оформление элементов.
- Добавить адаптивную раскладку.
- Улучшить состояния ошибок и успеха.
- Проверить читаемость на небольших экранах.

## Принципы

Одно основное действие на экран. Справка доступна по запросу. Игровая ситуация, условие, ответ, результат и подробное объяснение визуально разделены. Сначала показывается основная ошибка; детали раскрываются по запросу; эталон — после завершения упражнения.

## Шаблон экрана

1. Индикатор навыка и этапа.
2. Игровая ситуация.
3. Краткое условие.
4. Область ответа.
5. Основное действие отправки.
6. Результат проверки.
7. Дополнительное объяснение по запросу.

## Проверка UX

Проверять понимание задания, обнаружимость основного действия, различение фактов и условий, понятность feedback, исправление после feedback, адаптивность и отсутствие утечек скрытых данных.

Аудит по скриншотам не заменяет пользовательское тестирование и проверку доступности. Для точной привязки замечаний к экрану следует хранить исходные изображения рядом с документацией.
