## Цель на момент создания

Создать новое приложение для обучения игре Perudo. На первом этапе это тренажёр учебных ситуаций, а не платформа полноценных онлайн-партий.

## Зафиксировано на момент создания

- классический профиль правил: `PERUDO_ZYGOMATIC_CLASSIC_V1` (устаревший идентификатор; актуальный ruleset указан в нормативных контрактах);
- Calza отключено, Palifico включено;
- учебная система S1–S9;
- архитектурная концепция модульного монолита;
- отдельные контракты Game Domain, Exercise, Evaluation и Learning Progress.

## Не утверждено на момент создания

Перечень ниже исторический и не отражает последующие решения. В частности, не использовать его для повторного открытия уже закрытых правил Palifico или выбора модели исполнения.
