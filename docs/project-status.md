# Статус проекта

Версия документации: 0.1. Статус: начальная консолидация требований.

## Цель

Создать новое приложение для обучения игре Perudo. На первом этапе это тренажёр учебных ситуаций, а не платформа полноценных онлайн-партий.

## Зафиксировано

- классический профиль правил: `PERUDO_ZYGOMATIC_CLASSIC_V1`;
- Calza отключено, Palifico включено;
- учебная система S1–S9, подробно определены S2, S3 и S4;
- архитектурная концепция модульного монолита;
- отдельные контракты Game Domain, Exercise, Evaluation и Learning Progress;
- разделение полной игровой модели, публичного представления и учебного представления;
- сохранение событий, снимков состояния и версий схем;
- UX-принципы и результаты первичного аудита.

## Не утверждено

- физическая структура Python-пакетов;
- БД, веб-фреймворк и инфраструктура;
- локальная, серверная или гибридная модель исполнения;
- окончательные пороги освоения и числовые допуски;
- некоторые трактовки Palifico, требующие сверки с инструкцией выбранной редакции.

## Правило

Если решение не подтверждено явно, оно остаётся открытым вопросом. Не следует выдавать предположение за согласованный контракт.
