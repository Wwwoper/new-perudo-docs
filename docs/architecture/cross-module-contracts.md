# Межмодульные контракты Game Domain ↔ S2–S4

Версия: 1.0.

## Game Domain ↔ S2

Game Domain остаётся источником истины. Адаптер доменных событий формирует `TableTransition`; S2 отображает переход и не дублирует игровые правила.

## Game Domain ↔ S3

`CountContext` содержит `round_mode`, `ruleset_id` и `ruleset_version`. Учитываются только активные кубики. Закрытые значения кубиков соперников не передаются. `CountResult` сохраняет режим и версии правил.

## S3 ↔ S4

S3 передаёт `required_matches`, `hidden_dice_count`, режим и правила. S4 не пересчитывает собственные совпадения. Если требование уже выполнено, вероятность 100%; если требуемых совпадений больше числа скрытых кубиков — 0%.

## Game Domain ↔ S4

Вероятность одного скрытого кубика:

| Режим | Ставка | Вероятность |
|---|---|---:|
| NORMAL | грань 2–6 | 1/3 |
| NORMAL | единица | 1/6 |
| PALIFICO | любая грань | 1/6 |

`ProbabilityEvent` содержит `round_mode` и версии правил.

## Сквозные требования

- выбывшие участники видимы, но не входят в очередь и расчёты;
- Palifico и право игрока менять грань — независимые условия;
- S8 принимает решения, S4 рассчитывает вероятность, S3 считает кубики, S2 воспринимает стол;
- Dudo порождает согласованную последовательность событий в одной транзакции;
- `command_id` обязателен для всех изменяющих состояние команд.
