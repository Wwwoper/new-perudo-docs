# Сводная система контрактов

Версия: 1.0.

## Поток учебного упражнения

`config → generator → validation → persist → public view → answer → evaluation → feedback → progress`.

Экземпляр сохраняется после успешной генерации. Публичные данные не содержат эталон. Проверка на первом этапе локальная, но контракт допускает перенос на сервер.

## Ответственность модулей

- Game Domain — предметная истина о партии.
- Skills — описание навыков и зависимостей.
- Exercise Engine — генерация и жизненный цикл экземпляров.
- Evaluation — структурированная проверка.
- Feedback — пользовательское объяснение.
- Learning Progress — факты попыток и состояние навыков.
- Learning Strategy — выбор следующего упражнения.
- Presentation — визуализация разрешённых данных.

## Системные инварианты

1. Закрытые данные не раскрываются публичным компонентам.
2. UI не реализует игровые правила самостоятельно.
3. S3 не рассчитывает вероятность.
4. S4 не принимает игровое решение.
5. Evaluation не формирует пользовательский текст feedback.
6. Learning Progress не выбирает следующее упражнение.
7. Сохранённый экземпляр не зависит от повторного запуска генератора.
8. Повтор команды не создаёт повторное действие.
9. Восстановление не повторяет случайные операции.
10. Версии правил, схем и генераторов сохраняются независимо.
