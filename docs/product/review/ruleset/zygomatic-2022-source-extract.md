# Извлечение правил из официальной инструкции Zygomatic 2022

**Статус:** источник найден и извлечён; это evidence packet, а не утверждение владельца продукта и не замена Game Domain.

## 1. Идентификация источника

- Издатель: Zygomatic.
- Документ: *Perudo Classic — English Rules*.
- Маркировка редакции внутри PDF: `USN_RULES_2022.indd`, дата макета 29/08/2022.
- Язык: английский.
- Официальный URL: https://www.zygomatic-games.com/wp-content/uploads/2019/09/perudoclassic_en_rules_compressed.pdf
- Извлечённый документ: страницы 1–8 PDF; релевантные страницы правил — 3–6.
- Проверено: 2026-11-09.

## 2. Подтверждаемые правила источника

|---|---:|---|---|---|
| Z22-BID-01 | 3 | При повышении можно сохранить количество и увеличить грань; либо увеличить количество и выбрать любую грань; либо сделать ставку Paco по отдельному правилу | Обычные ставки нельзя свести к одному лексикографическому сравнению `(quantity, face)`; переход Paco — отдельная ветвь | Прямо указано |

## 3. Границы того, что источник не определяет в форме готового API

Источник не задаёт:

- структуру `GameState`, event names, DTO или persistence;
- точное имя и формат поля `has_declared_palifico`;
- алгоритм выбора следующего активного игрока при произвольном порядке/выбывании, кроме правила «слева», если потерявший кубик выбыл;
- программный порядок валидации и формат ошибок;
- точный момент вычисления «осталось два игрока» относительно команды разрешения Dudo и начала следующего раунда;
- отдельную таблицу переходов для участника с правом менять грань в Palifico — источник подтверждает право менять грань, но не описывает все граничные комбинации формально.

Эти пункты требуют проектной нормализации. Их нельзя цитировать как дословное правило источника.

## 4. Важные расхождения с текущей проектной документацией

1. Проектный контракт уже содержит persistent `has_declared_palifico`; это согласуется с Z22-PAL-03.
2. Контракт требует дополнительной проверки `active_players > 2` на старте раунда. Источник формулирует исключение как «когда осталось только два игрока»; точку измерения следует явно нормализовать.
3. Контракт содержит проектную таблицу изменения количества/грани для игрока с правом менять грань. Источник подтверждает само право, но не все строки таблицы.
4. Полная обычная иерархия ставок и Paco-переходы должны быть добавлены в нормативный контракт; без них нельзя утверждать, что валидатор ставок соответствует Zygomatic 2022.
