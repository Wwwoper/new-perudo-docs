# Учебный маршрут Perudo

Версия: 1.0
Статус: рекомендуемая продуктовая модель; зависимости служат рекомендациями для обучения, а не жёсткими блокировками.

## 1. Назначение

Документ определяет рекомендуемую последовательность освоения S1–S9, предпосылки навыков и доступные режимы обучения. Он не вводит общий рейтинг пользователя и не меняет контракт Learning Progress.

## 2. Рекомендуемый базовый маршрут

1. **S1 — Правила и механика:** понять правила, фазы партии и последствия действий.
2. **S2 — Восприятие стола:** научиться читать состояние стола и короткие последовательности изменений.
3. **S3 — Подсчёт кубиков:** научиться считать совпадения и необходимые совпадения на скрытых кубиках.
4. **S4 — Вероятность и оценка риска:** оценивать вероятность событий на основе количественного результата.
5. **S5 — Механика и оценка ставок:** понимать структуру и допустимое изменение ставки.
6. **S6 — Чтение истории торгов:** анализировать последовательности ставок и событий.
7. **S7 — Анализ соперников:** отделять наблюдения от предположений и оценивать надёжность выводов.
8. **S8 — Принятие решений:** сравнивать доступные действия и обосновывать выбор.
9. **S9 — Стратегия партии:** учитывать состояние партии и долгосрочные последствия.

Маршрут является рекомендуемым порядком первого знакомства. Он не означает, что все упражнения одного навыка должны быть завершены до знакомства со следующим.

## 3. Зависимости и предпосылки

| Навык | Рекомендуемые предпосылки | Обоснование |
|---|---|---|
| S1 | Нет | Вводит правила и механику |
| S2 | Базовый S1 | Нужно понимать, что обозначают элементы игрового состояния |
| S3 | S1, S2 | Нужны правила подсчёта и чтение ситуации |
| S4 | S3 | Вероятность рассчитывается на основе количества совпадений и скрытых кубиков |
| S5 | S1, S2 | Нужны правила и корректное чтение текущей ставки |
| S6 | S2, S5 | Нужны восприятие состояния и понимание допустимых ставок |
| S7 | S2, S6 | Нужны наблюдаемые факты и контекст поведения в торгах |
| S8 | В зависимости от задачи — S1–S7 | Решение может требовать разных комбинаций навыков |
| S9 | В зависимости от задачи — S1–S8 | Стратегия объединяет навыки в контексте партии |

Предпосылки определяют полезные рекомендации. Они не должны автоматически запрещать переход к другому навыку.

## 4. Диагностика и свободный выбор

Пользователь может:

- следовать рекомендуемому маршруту;
- самостоятельно выбрать любой доступный навык;
- пройти короткую диагностику перед началом;
- вернуться к ранее изученному навыку;
- выбрать смешанную тренировку из уже знакомых тем.

Если пользователь выбирает навык без подтверждённых предпосылок, система может предложить диагностическое упражнение или короткое повторение. Пользователь вправе продолжить без него, если упражнение не требует обязательного знания по правилам игры.

Диагностика — отдельный режим: её результаты используются для рекомендации стартового уровня, но не должны автоматически считаться освоением навыка.

## 5. Режимы обучения

### 5.1 LEARNING — обучение

- короткое введение в цель;
- один или несколько разобранных примеров;
- упражнения с явной поддержкой;
- постепенное снятие подсказок.

### 5.2 PRACTICE — тренировка

- новые варианты заданий;
- самостоятельные ответы;
- минимальная помощь до запроса;
- накопление метрик самостоятельности и точности.

### 5.3 REVIEW — повторение

- упражнения по назначенной причине повторения;
- новый экземпляр, а не повтор старой попытки;
- объяснение, почему тема предложена снова.

### 5.4 MIXED — смешанная тренировка

- сочетание нескольких навыков;
- задания используют только уже введённые знания либо явно отмечены как диагностические;
- вклад навыков в результат сохраняется раздельно.

Эти режимы соответствуют существующему контракту `LearningSession`.

## 6. Переходы между навыками

- Рекомендация следующего навыка не является обязательным переходом.
- Незавершённая попытка сохраняется и может быть продолжена по существующему жизненному циклу.
- Выбор другого навыка не удаляет и не сбрасывает прогресс текущего.
- Смешанные упражнения не должны скрывать, какой навык оценивается.
- Если ошибка указывает на пробел в предпосылке, система предлагает соответствующее упражнение, но не переписывает результат исходной попытки.

## 7. Критерий корректности маршрута

Маршрут считается продуктово корректным, если пользователь может понять рекомендуемый следующий шаг, свободно выбрать альтернативу, не теряет прогресс при переключении и не получает задания, требующие не введённых знаний без диагностической маркировки.
