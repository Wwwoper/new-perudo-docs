# Exercise Contract

Статус: согласовано.

## Модели

`Exercise`, `PublicExercise`, `PrivateExerciseData`, `Question`, `ExpectedAnswer`, `ExpectedFields`, `EvaluationCriteria`, `DiagnosticContext`, `ExerciseConfig`, `ExerciseGenerator`.

Публичная и закрытая части строго разделены. Эталон не передаётся ученику до завершения упражнения.

## Жизненный цикл

`config → generator → validation → persist → public view → answer → evaluation`.

Экземпляр сохраняется сразу после успешной генерации. Хранятся конкретный экземпляр, seed, версия генератора, конфигурация, `ruleset_id` и `ruleset_version`; одного seed недостаточно.

Одно упражнение может содержать несколько вопросов и последовательных шагов. Ответы используют типизированные структуры. Использование каждой подсказки фиксируется отдельно и не уменьшает балл автоматически.

Повторение создаёт новый вариант того же типа и сложности, а не повтор исходного экземпляра. Проверка локальная на первом этапе; контракт допускает перенос на сервер без изменения модели.

Ошибки генерации отделены от ошибок ученика. Некорректный экземпляр не попадает в учебную сессию. Сохранённый экземпляр воспроизводим независимо от последующих изменений генератора.
