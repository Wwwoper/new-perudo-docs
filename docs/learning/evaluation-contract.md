# Evaluation Contract

Версия: 0.1. Согласовано.

Модели: `AnswerSubmission`, `SubmittedAnswer`, `AnswerFormat`, `EvaluationResult`, `FieldResult`, `StepResult`, `DiagnosticResult`, `FeedbackResult`, `EvaluationCriteria`, `AnswerEvaluator`.

Проверка разделена на формат, поле, шаг и итог упражнения. Поддерживаются частичная оценка и зависимости между шагами. Правильное продолжение рассуждений после предыдущей ошибки получает частичный балл (follow-through credit). Необязательные шаги не влияют на обязательный итоговый балл.

Количество отправок не ограничено; каждая отправка неизменяема и сохраняется. Исправлять ответ можно только после получения feedback. Повторная отправка не должна дублировать операцию.

Правильный ответ раскрывается только после завершения всего упражнения, не после проверки отдельного вопроса. По умолчанию показывается основная ошибка; детали доступны по запросу. Ошибки разделяются на первичные, зависимые и независимые.

Evaluation возвращает структуру; Feedback формирует пользовательское объяснение и постепенно раскрывает основную ошибку, пояснение, подсказку, подробный разбор и эталон после завершения. Точные значения хранятся точно; допуски централизованы. Сохраняются версии упражнения, правил и механизма проверки.

Тестируются формат, частичная оценка, follow-through credit, optional steps, последовательность отправок, исправление только после feedback, отсутствие раннего раскрытия эталона, диагностика и отсутствие утечек закрытых данных.
