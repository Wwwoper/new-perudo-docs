# Дополнительные эталонные примеры для ruleset 2.0.0

**Статус:** `READY_FOR_REVIEW`; это подготовленные fixtures, а не утверждённые scored content.
**Нормативный источник:** `docs/contracts/game-domain.md`.
**Ruleset:** `PERUDO_CLASSIC_ZYGOMATIC_2022@2.0.0`.

## S1 — правила и механика

### S1-E06. Обычное повышение и граница грани

**Условие:** режим NORMAL. Текущая ставка — четыре пятёрки. Кандидат A — четыре шестёрки; кандидат B — четыре четвёрки; кандидат C — пять двоек.

**Вопрос:** какие кандидаты допустимы?

**Ожидаемый ответ:** A и C допустимы; B недопустим. При равном количестве грань должна быть выше; при увеличении количества грань может быть любой.

**Критерии:** отдельно оценить допустимость каждого кандидата; не использовать лексикографическое сравнение количества и грани.

### S1-E07. Palifico и исключение для двух игроков

**Условие:** после атомарного разрешения Dudo игрок перешёл с двух кубиков на один. Сценарий A: осталось три активных игрока. Сценарий B: осталось ровно два.

**Ожидаемый ответ:** A — следующий раунд PALIFICO, игрок начинает его; B — следующий раунд NORMAL.

**Критерии:** назвать точку проверки активных игроков после потери кубика и обновления выбывания; не проверять число до Dudo.

## S5 — механика ставок

### S5-E04. Переходы в Paco и обратно

**Условие:** NORMAL. Текущая ставка — семь четвёрок. Кандидат A — четыре Paco; кандидат B — три Paco. В отдельной ситуации текущая ставка — четыре Paco; кандидат C — девять двоек; кандидат D — восемь шестёрок.

**Ожидаемый ответ:** A и C допустимы; B и D недопустимы. Переход в Paco требует не менее `ceil(7/2)=4`; выход из четырёх Paco требует не менее `2*4+1=9` обычных совпадений.

**Критерии:** применить правильную формулу в правильном направлении; не путать допустимость перехода с вероятностью ставки.

### S5-E05. Paco как грань в Palifico

**Условие:** режим PALIFICO. Игрок ранее не объявлял Palifico. Текущая ставка — четыре Paco. Кандидат A — пять Paco; кандидат B — пять троек.

**Ожидаемый ответ:** A допустим; B недопустим для этого игрока, поскольку он обязан сохранить грань. Paco в этом режиме — выбранная грань, не джокер.

**Критерии:** не применять NORMAL коэффициенты перехода Paco; не разрешать смену грани игроку без исторического права.

## S3/S4 — режимный подсчёт и вероятность

### S3-E05. Paco не добавляется к грани в Palifico

**Условие:** режим PALIFICO; собственные кубики игрока — `3, 1, 1, 4, 6`; ставка — три тройки.

**Ожидаемый ответ:** собственных совпадений — одно; две единицы не добавляются к тройкам.

**Критерии:** явно назвать режим; не использовать NORMAL правило джокера.

### S4-E07. Вероятность в Palifico

**Условие:** режим PALIFICO; неизвестны шесть кубиков; оценивается вероятность получить не менее двух троек. Известные собственные кубики уже учтены отдельно; скрытые кубики независимы.

**Ожидаемый ответ:** биномиальная модель с `n=6`, `p=1/6`, событие `X>=2`:

`1 - (5/6)^6 - 6*(1/6)*(5/6)^5 = 12281/46656`.

**Критерии:** использовать `p=1/6`, а не `1/3`; обозначить событие «не менее двух», а не «ровно два».

## S6 — история торгов

### S6-E06. Восстановить Paco-переход

**Условие:** в NORMAL журнал содержит последовательность ставок: семь четвёрок → четыре Paco → девять двоек. Все ставки приняты.

**Ожидаемый ответ:** последовательность допустима: `4 >= ceil(7/2)`; после четырёх Paco обычная ставка должна иметь количество не меньше девяти. Из журнала нельзя выводить мотивы игроков.

**Критерии:** восстановить каждую пару переходов; не смешивать `BID_PLACED` и `TURN_ADVANCED`.

## S8 — принятие решений

### S8-E06. Оценивать только легальные действия

**Условие:** NORMAL; текущая ставка — семь четвёрок. Доступные варианты: повысить до семи пятёрок, перейти на восемь двоек или объявить Dudo. Предложение «шесть шестёрок» недопустимо. Цель решения — максимизировать заданную в упражнении вероятность продолжить участие, а не гарантировать выигрыш партии.

**Ожидаемый ответ:** сначала исключить «шесть шестёрок» из action set; затем сравнить оставшиеся действия по явно заданной цели и доступной информации.

**Критерии:** legality предшествует quality; оценка не опирается на скрытые значения или будущий исход.

## S9 — стратегия партии

### S9-E06. Условная ветвь для Palifico

**Условие:** игрок с двумя кубиками рассматривает долгосрочный план. Триггер следующего режима зависит от результата текущего раунда и числа активных игроков после Dudo.

**Ожидаемый ответ:** план должен содержать ветвь: если игрок теряет четвёртый кубик и после Dudo остаётся больше двух активных игроков — следующий раунд Palifico; если остаётся ровно два — NORMAL. В Palifico план использует отсутствие джокеров и проверяет историческое право менять грань.

**Критерии:** условие связано с наблюдаемым состоянием; не обещать активацию Palifico до разрешения Dudo; указать триггер пересмотра при изменении числа активных игроков.

## 10. Review requirements

Для каждого нового fixture reviewer должен проверить публичное условие, эталон, accepted alternatives, критерии, границы и соответствие версии `2.0.0`. До заполнения review record эти примеры не должны влиять на mastery или progress evidence.
