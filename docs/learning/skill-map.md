# Карта навыков Perudo

Версия: 0.1.

| ID | Навык | Назначение |
|---|---|---|
| S1 | Правила и механика | Понимать правила и последовательность игры |
| S2 | Восприятие стола | Читать текущее состояние стола |
| S3 | Подсчёт кубиков | Считать совпадения и недостающее количество |
| S4 | Вероятность и оценка риска | Оценивать вероятность математического события |
| S5 | Механика и оценка ставок | Понимать структуру и изменение ставок |
| S6 | Чтение истории торгов | Анализировать последовательность ставок |
| S7 | Анализ соперников | Работать с наблюдаемым поведением |
| S8 | Принятие решений | Сравнивать игровые варианты и выбирать действие |
| S9 | Стратегия партии | Строить долгосрочную стратегию |

## Маршрут мышления

Увидеть ситуацию → определить известное → оценить неизвестное → рассчитать вероятность → интерпретировать действия → сравнить варианты → принять решение → оценить качество решения.

## Состояния навыка

`NOT_STARTED`, `LEARNING`, `PRACTICING`, `MASTERED`, `NEEDS_REVIEW`.

Освоение учитывает точность, самостоятельность, разнообразие типов упражнений, повторяемость ошибок и устойчивость результата во времени. Один accuracy недостаточен.

Предварительные пороги: S2 — 85–90%, S3 — около 90%, S4 — 85–90%. Значения и минимальное число попыток требуют калибровки.

## Границы

S2 читает стол и восстанавливает короткие последовательности; S3 выполняет количественный подсчёт; S4 рассчитывает и интерпретирует вероятность; S6 анализирует историю торгов; S8 принимает решение.
