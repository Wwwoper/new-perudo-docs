# Матрица покрытия учебных целей Perudo

Версия: 1.0
Статус: предварительная матрица полноты продуктового каталога; не является доказательством готовности всех упражнений.

## 1. Назначение

Матрица связывает навыки S1–S9 с видами учебной деятельности, диагностикой и критериями оценки. Она используется для проверки полноты каталога и выявления пробелов до передачи спецификации в разработку.

## 2. Матрица покрытия

| Навык | Распознавание | Применение | Анализ | Самостоятельное решение |
|---|---|---|---|---|
| S1 — Правила и механика | Да | Да | Да | Частично: допустимость и последствия действий |
| S2 — Восприятие стола | Да | Да | Да | Да: восстановление состояния |
| S3 — Подсчёт кубиков | Да | Да | Да | Да: полный подсчёт |
| S4 — Вероятность и риск | Да | Да | Да | Да: самостоятельная оценка события, не выбор хода |
| S5 — Механика ставок | Да | Да | Да | Да: поиск допустимого продолжения |
| S6 — История торгов | Да | Да | Да | Да: восстановление и объяснение последовательности |
| S7 — Анализ соперников | Да | Да | Да | Да: вывод с учётом ограничений данных |
| S8 — Принятие решений | Да | Да | Да | Да |
| S9 — Стратегия партии | Да | Да | Да | Да |

«Да» означает, что каталог содержит подходящий тип упражнения. «Частично» отмечает, что самостоятельный стратегический выбор не является целью S1.

## 3. Границы ответственности и контроль смешения навыков

| Навык | Что проверяет | Что не должен подменять |
|---|---|---|
| S1 | Понимание правил и последствий | Подсчёт, вероятность, стратегический выбор |
| S2 | Чтение текущего состояния и коротких изменений | Количественные вычисления и полный анализ торгов |
| S3 | Количество совпадений и необходимых совпадений | Вероятность и решение |
| S4 | Вероятность и её интерпретацию | Выбор ставки и игровое решение |
| S5 | Механику и допустимость ставки | Анализ намерений и стратегическую ценность |
| S6 | Наблюдаемую историю торгов | Неподтверждённые выводы о намерениях |
| S7 | Качество выводов о поведении по наблюдениям | Утверждение о достоверном распознавании блефа/психологии |
| S8 | Качество выбора в доступной ситуации | Оценку решения только по фактическому исходу |
| S9 | Долгосрочный контекст партии | Предположение об одном универсально лучшем ходе во всех условиях |

## 4. Критерии оценки упражнения

Для каждого типа упражнения должны быть определены:

- соответствие ответа формату;
- правильность содержимого;
- оценка обязательных полей и шагов;
- независимые и зависимые ошибки;
- правила partial/follow-through credit;
- допустимые альтернативные ответы;
- диагностические коды;
- критерии завершения;
- обратная связь по основной ошибке.

Для упражнений S7–S9, где возможны несколько разумных вариантов, критерии должны оценивать качество рассуждения, а не совпадение с единственным предписанным действием.

## 5. Критерии качества рассуждения для S7–S9

Оценка может учитывать следующие измерения:

1. **Фактическая опора:** использованы существенные сведения, доступные в условии.
2. **Корректность правил:** игровые правила применены без противоречий.
3. **Работа с неопределённостью:** предположения не представлены как факты.
4. **Полнота последствий:** учтены существенные последствия выбранного варианта.
5. **Логическая связь:** вывод следует из приведённых оснований.
6. **Альтернативы:** при необходимости замечены другие допустимые варианты.

Не каждое упражнение обязано проверять все измерения. Набор применимых критериев определяется целью конкретного упражнения.

## 6. Проверки покрытия перед выпуском

- у каждого навыка есть несколько типов упражнений, а не один шаблон;
- для каждого навыка проверяются распознавание и самостоятельное применение;
- для сложных навыков предусмотрены анализ и перенос на новую ситуацию;
- у каждого типа есть диагностируемые ошибки;
- ни один тип не требует неоговорённой предпосылки;
- все обязательные учебные цели связаны с упражнениями и проверяемыми критериями;
- интеграционные упражнения не скрывают основной навык-владелец;
- прогресс и рекомендации сохраняют раздельность навыков.

## 7. Статус и ограничения

Матрица отражает покрытие на уровне предложенного каталога. Она не подтверждает наличие готовых заданий, валидированных порогов или эмпирическую эффективность обучения. Для S1 и S5–S9 требуется последующая спецификация конкретных критериев, диагностик и тестовых примеров. Для S2–S4 действуют существующие подробные контракты.
