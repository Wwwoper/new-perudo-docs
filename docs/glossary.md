# Глоссарий

| Термин | Значение |
|---|---|
| Game Domain | Предметная модель партии, правил и переходов состояния |
| Ruleset | Идентифицированная и версионированная редакция правил |
| Exercise | Сохранённый экземпляр учебного упражнения |
| PublicExercise | Разрешённая ученику часть упражнения |
| PrivateExerciseData | Эталон и закрытые данные для проверки |
| Evaluation | Структурированная оценка отправленного ответа |
| Feedback | Пользовательское объяснение результата проверки |
| SkillProgress | Текущее состояние освоения отдельного навыка |
| Snapshot | Снимок состояния, восстановленный на определённой позиции журнала |
| Palifico | Специальный режим следующего раунда с отдельными правилами ставок |
| Dudo | Оспаривание текущей ставки |
